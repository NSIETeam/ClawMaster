# Agent Note：桌面可选组件恢复

Status: implemented

[English](2026-09-17-desktop-optional-component-recovery.md) | 中文

## 决策

功能组件不可用时，ClawMaster 仍保持桌面核心可用。配置文件准备阶段会跳过无效或缺失的可选组件包，并记录组件故障日志。启动恢复仅在禁用白名单内的功能条目后重试。主前端、桌面策略、Guard、权限和审批条目不可恢复；这些条目失败仍会阻止启动。

## 考虑过的替代方案

拒绝在启动错误后禁用所有加载器条目，因为这可能让安全组件损坏或缺失的应用看起来仍然成功启动。拒绝在创建配置文件前要求每个已打包的功能包都通过校验，因为笔记、Office、连接器或更新器缺失时，不应阻止 ClawMaster 的其余部分打开。

## 后果

可选组件不可用时，不会出现在活动桌面配置中；后续启动通过校验后才会重新加入。可选插件激活失败时，本次恢复启动会禁用它，桌面外壳会提示其加载器条目 ID。新增桌面功能时必须明确它是否可选；如果适合启动恢复，还必须把加载器条目 ID 加入 Rust 白名单。核心应用与安全条目仍保持失败即拒绝。

## 验证

`desktop-defaults.test.mjs` 验证缺失或版本错误的可选组件会被跳过并写入核心配置，而前端包缺失仍会失败。Supervisor 测试验证可禁用可选集成，同时不能禁用前端、Guard、sandbox、approval、permission 和未知条目。各已安装平台上的恢复流程，以及每个被禁用功能的用户可见状态，仍属于桌面验收范围。
