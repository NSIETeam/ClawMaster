# Agent Note: 思维审视技能套件随包预置分发

Status: implemented

[English](2026-09-21-thinking-review-skill-suite.md) | 中文

## 问题

ClawMaster 的用户带来想法、计划、产品和决策，希望在投入资源前得到一次客观的压力测试。已安装的技能要么产出成果物、要么执行工作流——没有一个会挑战用户自己的思考。产品要求把五种思维方式做成审视能力：纳瓦尔·拉维坎特的杠杆与长期博弈思维、查理·芒格的逆向思维、埃隆·马斯克的第一性原理与成事五步法、史蒂夫·乔布斯的产品与品牌标准。该能力必须触达每一个安装，包括离线的桌面安装，且不需要市场插件安装步骤。

## 决策

六个种子技能随 [packages/core/skills-seed](../../../../packages/core/skills-seed/) 分发：`thinking-council` 编排一次完整的多模型审视；`first-principles-review`、`five-steps-review`、`inversion-review`、`naval-lens` 与 `product-brand-review` 各自以完整深度承载一个框架。`seedDefaultSkills()` 在启动时把每个新的种子目录拷入 `~/.clawmaster-user/skills/`，因此无论全新安装还是已有安装，套件都会自行就位；用户改过的技能永远不会被覆盖。

每个技能固定的是审视契约，而不是自由发挥的建议。董事会先把用户想法重述为最强版本再展开挑战，把发现按致命/重要/次要分级，对五个维度打分，并以唯一裁决收尾——GO、GO WITH FIXES 或 NO-GO——外加必答问题清单与止损条款。五个单项技能固定各自框架的机制：第一性原理的假设审计、五步法"先质疑需求、先删后优"的顺序约束、逆向思维的预验尸加误判清单加止损条款、纳瓦尔的四类杠杆审计加复利评估、乔布斯标准的简洁审讯/说不/端到端走查加品牌承诺检验。所有技能要求数字必须有来源或标注为估算，并声明裁决是辅助用户判断，不是替代。

技能描述带有中英文触发词。主动调取依赖既有的技能纪律系统段与 `<available_skills>` 目录；除种子目录本身外不涉及任何代码改动。

## 测试

对用户技能目录跑一次 `FileSystemSkillProvider` 扫描——即生产发现路径，用 stub 上下文在运行中的会话之外驱动——六个技能全部凭 frontmatter 被发现，解析告警为零。frontmatter YAML 另做了独立校验，包括 name 与目录名的一致性。在这台机器上，套件还以用户层方式实际运行；已安装的桌面 0.2.3 构建在下一个包含该目录的打包版本出现前，仍只预置其自带的办公技能。

## 备选方案

**一个包含全部五个框架的单体技能。** 目录匹配与触发词失去粒度，点名某个框架的用户会加载全部五套指令。董事会已提供快速/深度两种模式的五镜组合；独立单项技能保留了按框架加载。

**把框架写进系统提示或 agent 循环。** 每个会话都要为此付费，包括从不审视想法的会话；且仓库约定新行为走扩展点，不改循环。

**走企业管理技能所在的插件市场渠道分发。** 该渠道的源码不在本仓库内，且需要市场安装步骤；种子是本仓库自有、开箱即得的分发路径。

## 后果

由本源码构建的每个安装在下一次启动即获得套件，内容随产品一起版本化、可评审。统一的输出契约让审视结果在不同想法之间、不同时间点上可比较。

代价是输出长度：深度五镜审视是很长的回复，因此董事会为日常决策定义了快速模式。框架本身按设计就是有立场的；技能用证据规则、每条发现附"如何证伪"、以及明确的决策辅助声明来约束这一风险。
