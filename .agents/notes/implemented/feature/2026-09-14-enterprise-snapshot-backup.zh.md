# Agent Note: 导出已校验的企业快照

Status: implemented

[English](2026-09-14-enterprise-snapshot-backup.md) | 中文

## 问题

本机 CRM/ERP 存储已有持久化和审计，但面板没有提供用户控制的备份操作，尽管其中保存了业务记录。

## 决策

在两个面板的标题栏增加下载操作，将当前已观察且通过 schema 校验的企业快照导出为带日期的 JSON 文件。面板也能选择备份文件，显示校验后的数量和 revision，并在调用带 revision 栅栏的恢复路由前要求明确确认。Host 存储以事务原子替换，并拒绝过期确认。

## Alternatives considered

**从浏览器复制 SQLite 文件。** 浏览器代码无法安全访问 Host 数据库路径，而且会绕过已认证的快照约定。

**导入时自动恢复。** 隐式替换可能破坏较新的记录；因此存储原语要求独立复核流程、版本检查和格式检查。

## Consequences

操作员可以保留可移植的本机快照用于恢复或审计。恢复必须选择文件、查看摘要并针对当前 revision 确认；仅选择文件不会触发恢复。

## Acceptance

- CRM 和 ERP 在有快照时显示本地化下载操作；
- 导出包含完整已观察快照并使用带日期的文件名；
- 导出不会修改存储；
- 前端构建和测试通过。
