# Agent Note: 桌面测试夹具目录分配

Status: implemented

[English](2026-09-15-desktop-fixture-directory-allocation.md) | 中文

## 问题

桌面载荷布局测试会并行运行。使用进程 ID 与墙上时钟时间戳命名目录，会让两个夹具在同一时钟刻度内选择相同路径。因此，目录创建可能在实际测试载荷解析器之前就因 `AlreadyExists` 失败。

## 决策

每个载荷布局夹具持有一个 `tempfile::TempDir`。分配器以原子方式占用目录，所有权在测试结束后释放目录。该依赖仅用于测试；打包运行时行为与资源查找保持不变。

## 考虑过的替代方案

串行执行仍会让资源分配依赖调度。增加延时仍会让它依赖时钟分辨率。两者都无法建立独立所有权。

## 后果

现有成功与拒绝用例保留原有断言，可以在所有桌面测试主机上并行运行。已观察到的目录冲突提供回归证据；测试验证载荷解析器，而不重复测试临时目录库。
