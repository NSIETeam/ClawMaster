# Agent Note: 通过 Graph Memory 统一笔记与记忆检索

Status: implemented

[English](2026-09-14-graph-memory-unified-retrieval.md) | 中文

## 问题

ClawMaster 同时提供人管理的 Notes 笔记库与 agent 管理的长期记忆服务。Notes 上下文桥只匹配笔记名称和路径，不读取笔记正文，并在同一 agent 首次命中后抑制该笔记。因此，即使两个存储包含同一主题，它们仍是两套独立检索系统。

## 决定

桌面 profile 在 Notes 之后内置 `@clawmaster/dsh-graph-memory`，并关闭 Notes 包中只按名称匹配的桥。Graph Memory 把笔记正文与只读 OpenViking 记忆编入同一份词法图和结构图。两种文档使用同一套 BM25 排序，不按来源加权。结果保留命中词、遍历关系，以及内容完全相同或标题相同的重复标注。

每回合第 1 个 step，Graph Memory 在读取来源前先沿 `agent/pre-step` waterfall 委托。它追加一条来源为 `clawmaster-graph-memory` 插件、`form: snapshot` 的消息。后一回合会覆盖此前贡献。Notes 服务无法列出笔记库时，监听器记录失败并原样返回委托结果。

## 存储与来源所有权

组件通过 `ctx.storage` KV 单元持久化一份验证后的图快照。桌面 bundle 在 `~/.clawmaster/components/graph-memory/graph.sqlite` 提供 SQLite 后端；该路径位于所有被索引目录之外。完整替换防止读取方观察到只重建了一部分的图。

笔记继续由 `clawmasterNotes` 所有；Graph Memory 不绕过该服务读取笔记目录。OpenViking 继续作为外部只读来源。可选文件系统来源必须显式配置。文本文件贡献词法正文，其他文件类型只贡献元数据。

文件读取使用原生路径。图中的文件 ID 和路径使用相对于来源目录的 `/` 分隔符，使文件名匹配和 wiki 链接解析不依赖操作系统。规范化只作用于这些相对路径；来源路径、文件名和文档正文保留原始字符。派生快照在刷新时整体替换，因此规范化 ID 不需要迁移来源文档。

## 写回所有权

既有 Guard 结果审查与 Notes 工具负责笔记写入。Graph Memory 提供只预览的分类器：结论、决定和证据进入笔记；偏好和稳定事实进入记忆；每条拟写记录带有互相的 `[[链接]]`。分类器没有写入路径。本变更没有写入或删除记忆的授权，因此长期记忆摄取继续保持缺失。

## 验证

输出字段使用 DSH 的 schema 描述器，不能直接传入带有 `anyOf` 或长度限制的 zod JSON Schema。真实 ToolRuntime 注册并执行全部三个工具，校验返回值；刷新只返回计数，完整图保留给面板。

包测试覆盖 `ctx.storage` 替换、直接工具调用、从 zod 派生的参数及 DSH 输出 schema、同权来源检索、逐回合 snapshot 注入、失败时保留 step、重复依据、二进制只索引元数据、原生文件系统根路径下稳定的图路径与不变的文本哈希，以及主题/相似项渲染。独立的只读命令索引真实 Notes 笔记库与已配置的 OpenViking 服务；若没有任何查询同时召回两类内容，命令就失败。

算法改编基线是独立开发的 GraphRAG 源码树，其稳定聚合 SHA-256 为 `73c9775d42850789f4e73ea298cfab250eb98dc18917ddeca1772ed60bf7a222`；实际观察到的门禁为主包 50 项测试、工具包 9 项测试。

## 考虑过的替代方案

**保留 Notes 名称桥。** 它无法检索只在正文出现的概念，并在一次命中后抑制仍相关的笔记，因此不能让笔记成为与记忆平等的来源。

**让每个工具运行独立 CLI。** 子进程会重复生命周期与错误处理、绕过共享存储服务，并在产品内保留一个独立 SQLite 所有者。

**复制完整独立包。** CLI、watch 进程、评估运行器、SQLite 适配器和静态 HTML 查看器会重复产品已有服务。组件保留零依赖图算法，并用 Notes、storage、认证路由和侧边栏替换这些适配器。

**自动把笔记写入 OpenViking。** 这会在没有独立授权、冲突处理或删除策略时创建长期记忆写入路径。产品保留只预览的摄取边界。

## 后果

同一条查询与同一条开场上下文路径可以召回笔记和记忆正文，并提供可检查的依据。人可以在侧边栏看到同一份图中的主题和相似文档。刷新成本随当前来源规模增长，因为实现会重建一份完整快照。在相关 owner 批准操作前，语义向量边与实际执行的互相写回仍不可用。
