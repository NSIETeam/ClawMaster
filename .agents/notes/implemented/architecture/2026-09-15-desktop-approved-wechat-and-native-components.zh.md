# Agent Note：经过授权的微信读取与桌面原生组件

Status: implemented

[English](2026-09-15-desktop-approved-wechat-and-native-components.md) | 中文

## 问题

JavaScript 插件可以成功加载，但安装后的桌面应用仍可能缺少它的原生执行程序。这一区别直接影响微信读取：工具需要可用的平台提供方，并且必须在检查消息内容前获得针对具体聊天的授权。桌面升级还需要与通过便携接入包挂载的更新器共存。

## 决策

[RPA 组件](../../../../frontends/rpa/README.zh.md)以 DSH 工具形式提供 `wechat_read`。每次调用都要求存在 Agent 会话，并获得绑定到所选聊天确切名称和消息数量上限的 `allowed-once` 批准。工具在批准前不启动原生进程，拒绝取消操作和已变化的参数，并校验返回范围。授权说明明确告知返回的消息会进入会话记录和所配置的模型。聊天文字被标记为不可信数据。

macOS 提供方核验微信应用身份、所选聊天标题和可见消息区域。它先在批准的数量上限内选取可见消息引用，再读取文字；存在歧义或不支持的界面会拒绝读取。它不选择其它聊天、不滚动、不截图、不读取数据库、不持续监听，也不发送消息。Windows 和 Linux 返回明确的不支持结果。系统辅助功能权限与每次调用的 DSH 批准用途不同，不能相互替代。本工具的审批约束不覆盖直接访问本机操作系统的行为。

[桌面打包脚本](../../../../apps/desktop-tauri/README.zh.md)为每个发布目标编译 RPA 执行程序，将其放入组件的平台目录。打包过程核验二进制格式、架构、大小、摘要和非交互式能力查询。安装后运行时检查解析实际分发的执行程序，并通过生产 Host 发现工具。源码测试明确跳过缺失原生程序的情况；发布验收要求程序存在，不能把跳过测试当作原生验证证据。

桌面装配过程为打包后的更新器添加由桌面维护的 bundle 补丁及清单声明，保留已发布组件压缩包和源码清单。运行时直接列出 `@clawmaster/dsh-updates`，使已有接入包能够发现已安装的更新器并拒绝重复引导安装。这些打包增补纳入桌面 bundle 的来源记录。准备 profile 时，通过 DSH 所属的解析器读取补丁数据；如果已有层拥有更新器条目，则省略桌面插入层。用户补丁字节、组件配置和停用选择保持不变。组件的[安装与激活决策](2026-09-15-installed-dsh-component-updates.zh.md)继续定义签名下载、一次性批准的准备操作和暂存的自身更新；内置组件不改变这些操作。

## 考虑过的替代方案

**采用不受限的个人账号自动化包。** 同时提供导航、发送和联系人修改的包超出了有限读取请求所需的权限。提供方只执行所选聊天的可见消息读取。

**读取桌面快照后过滤输出。** 采集后过滤可能让读取程序接触侧栏预览、草稿或未获批准的消息正文。在提取文字前选择元素引用，使采集保持在批准的操作范围内。

**把 JavaScript 加载成功当作原生验收。** 缺失程序或平台错误可能直到用户首次调用工具时才暴露。按目标平台打包并检查实际分发的运行时，可以覆盖这一故障。

**始终插入桌面更新器条目。** Cordis 插入不会根据相同标识符自动去重。检测已有贡献可以保留用户的更新器，并防止重复注册命令。

## 影响

即使执行程序和审批均可用，微信界面变化仍可能导致无法读取。不支持的布局会拒绝执行，不会扩大范围。合成辅助功能夹具验证选择行为。ACP 的[批准](../../../../snapshots/acp/wechat-read-approved/snapshot.yml)和[拒绝](../../../../snapshots/acp/wechat-read-rejected/snapshot.yml)录制会话场景仅使用合成消息，通过发布的 profile 验证一次性决策、工具输出持久化和辅助程序调用。真实客户端的授权读取仍是独立的验收证据，也不代表支持完整历史记录。

RPA 原生产物与平台相关。它们随匹配的桌面安装包分发，不作为一个通用组件压缩包对外提供。安装包升级保留 DSH 凭证、设置和会话，通过原生更新流程替换产品程序。

更新器 0.1.1 同时校验原始 tar 头路径与平台规范化后的条目路径。Windows 目录重命名发生冲突时，只有在真实目录、普通文件、长度与摘要全部校验通过后才复用缓存；无关的权限失败仍会报错。已发布的 0.1.0 文件保持不可变，用户已挂载的更新器版本保持原样。Linux 原生状态通过系统 Secret Service 保存各次 helper 调用共享的加密密钥；服务不可用时不得退回临时凭证或明文存储。Linux 发布测试使用私有 D-Bus 会话中的自有 Secret Service 和一次性密钥存储。
