# Agent Note: 撤回旧版原生发布并重置桌面版本

Status: implemented

[English](2026-09-24-withdraw-native-release-history.md) | 中文

## Problem

公开发布历史中包含产品负责人判定不可用、并要求在桌面版本号重置为 `0.0.1` 前撤回的桌面版与 Android 版。若仍公开这些发布信息或原生更新路径，客户端就可能发现或下载已不再获准使用的产物。

## Decision

按已批准的重置范围删除 GitHub 桌面版与 Android 发布及其版本标签，同时保留 Git 提交历史、组件版本和无关标签。新的产品目标仅包含桌面端。根路径的旧原生 manifest 与版本路由不再提供服务；Nginx 兜底返回 404，组件与便携更新包路由保留。公开检查观察到退役 manifest 路由返回 404，抽查的已撤下安装包 URL 返回 404 或 410。尚未验证服务器上旧文件是否已物理删除；恢复副本必须保存在公开目录之外。

编译时指向已退役根通道的已安装版本，无法通过服务器或 profile 配置发现替代端点。此类版本的用户须手动安装受支持的桌面版本。GitHub 仍负责构建溯源与发布产物；更新服务器只镜像已验证文件。

正式发布仍须等待：精确标签提交的 CI 产物、四个桌面目标全部通过安装后验收、有效的平台签名与公证，以及独立发布审核人配置。重置版本号不会免除发布验收。

## Alternatives considered

**保留旧发布页并标记为有问题。** 保留页面和标签仍会展示已撤回产物，可能被误认为可用下载；负责人批准删除这些公开版本记录，同时保留提交历史。

**为已安装客户端保留旧原生端点。** 这会继续提供已撤回的软件包，并保留进入负责人已否决版本的自动路径。对于无法更改编译时端点的客户端，接受手动重装作为代价。

**删除整个更新服务器目录。** 组件分发和便携更新包是独立的可用路径，因此只退役桌面原生发布端点。没有服务器端验证时，不能宣称物理状态目录已删除。

## Consequences

Git 历史仍可供调查，但已删除的发布和版本标签不再提供公开安装链接。历史 manifest 的解析与生成仍可用于离线校验，不能证明旧通道仍在服务。组件和便携更新包继续独立分发。使用已退役原生 URL 的现有安装需要手动安装；精确标签构建通过签名平台验收前，仍不得发布。
