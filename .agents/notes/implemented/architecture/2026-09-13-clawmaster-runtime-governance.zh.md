# Agent Note：ClawMaster 运行时治理

Status: implemented

[English](2026-09-13-clawmaster-runtime-governance.md) | 中文

## 问题

已安装运行时的变化独立于记忆中的路径与版本。载荷摘要能证明字节身份，但不能证明哪份源码生成了 JavaScript。桌面默认配置还需要受控写入与有界工作量，同时避免维护第二套 DSH 执行引擎。

## 决策

[壳决策](../feature/2026-09-12-clawmaster-shell-over-dsh.zh.md)继续负责载荷来源与 Workspace 保护。本记录负责实时观测与执行治理；两者均不替换历史 Session 数据或 OpenViking 记忆。

原生壳在 Host 就绪后发布私有运行时身份。实时 Host 每次重新读取并要求 PID 与自身一致，再通过 `runtime_status` 和 DSH 持久运行时上下文组装提供带时间戳的事实。正常退出仅将自身这一代标记为停止。记录缺失、已停止或不匹配时返回不可用；记忆值从不充当回退。原始文件是带日期的观测，而非崩溃后独立的存活探针。源码开发与 WSL 启动不声称具有此原生身份。[桌面 README](../../../../apps/desktop-tauri/README.zh.md)负责记录位置与生命周期说明。

前端通过 DSH 单调工具守卫执行 RSS 准入，并通过执行 waterfall 限制高负载工具函数的重叠数量。它在委派前预留容量，函数结束后释放。拒绝后仍可使用诊断，不终止进行中的工作或其他应用。可配置限额及其范围归[前端 README](../../../../frontends/dsh/README.zh.md#model-experience)所有。

ClawMaster profile 选择 DSH 受控文件预设与常规审批。子 Session 保留原始委派事件；实时祖先授权更少时，DSH 规范 setter 在模型步骤或工具之前追加更窄权限。祖先缺失时降为只读；子代理审批保持不可用。这一产品约束保留 DSH 历史委派快照，不重写已发布 Session 记录。冷恢复测试覆盖实际文件系统拒绝与持久权限收紧。前端 README 负责可配置默认值及其优先级。

## 考虑过的替代方案

**在长期记忆中存储当前路径。** 记住一次观测无法证明进程仍在运行，也无法证明升级是否选择了另一代运行时。

**在运行时携带 Git 元数据。** 提交与源码记录能建立可追溯性，无需把仓库历史、配置或凭据带入应用资源。

**空闲内存不足时终止进程。** 空闲内存快照不能指出可回收内存，也无法确定哪个应用的工作能安全中断。准入与有界重叠保护自身工作，不作整机保证。

## 后果

运行时观测通过既有上下文与工具结果路径进入 Session 日志。无密钥 AgentLoop 记录将回放消息与实际模型输入比较；原生状态测试和工具分发测试拒绝陈旧身份、格式错误记录、RSS 超额及并发超额。未注册的空版本目录不占用回滚保留名额；已注册 Workspace 目录仍受保护。资源预算覆盖 Host RSS 与选定工具函数的重叠执行，不覆盖脱离的进程、返回后的后台工作、原生编辑器或其他应用。
