# Agent Note: 仅测试已声明的桌面升级路径

Status: implemented

[English](2026-09-25-reset-release-upgrade-acceptance.md) | 中文

## 问题

发布校验器要求每个安装器都提供通用的数据保留场景，并要求每条已声明的旧版本升级路径单独提供保留结果。ClawMaster 0.0.1 是重置版本，已接受的安装方式是手动重装，因此没有需要测试的自动升级路径。

## 决策

0.0.1 的验收清单可以将 `supportedUpgradeVersions` 设为空数组。后续版本必须至少列出一条受支持的自动升级路径。校验器会在各旧版本对应的矩阵中检查每条已声明路径，因此不再额外要求重复的通用升级保留场景。

## 考虑过的替代方案

**保留通用升级场景。** 这会重复检查每条旧版本的数据保留情况，还会错误要求采用手动重装方式的版本必须具备自动升级路径。

**允许所有版本都不支持升级。** 后续版本可能会悄悄取消已承诺的升级路径，因此只有明确重置的 0.0.1 可以不声明自动升级。

## 后果

重置版本仍须提供安装包签名、干净安装、首次启动、重启、故障恢复、核心功能及真实模型请求的证据。空升级列表记录手动重装政策，不会降低安装器或运行时检查要求。后续版本仍需为每条声明支持的旧版本升级路径提供数据保留证据。

## 验证

`release-acceptance.test.mjs` 验证 0.0.1 可以使用空升级矩阵，后续版本则不能。相同测试仍会拒绝未保留设置、凭据、会话或业务数据的已声明升级路径。[已安装版本验收说明](../../../../apps/desktop-tauri/acceptance/README.zh.md)定义了清单规则。
