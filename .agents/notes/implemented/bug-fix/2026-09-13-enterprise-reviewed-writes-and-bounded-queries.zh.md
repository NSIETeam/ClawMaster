# Agent Note: 企业写入复核与有界查询

Status: implemented

[English](2026-09-13-enterprise-reviewed-writes-and-bounded-queries.md) | 中文

## 问题

WatchDog 巡检不得在没有用户决定的情况下修改业务记录。DSH 文件权限管理文件系统操作，而企业工具直接写入 SQLite。将联系人和订单草稿写入视为低风险，会使这些记录在没有审批时仍可修改，包括委派 Session 发起的写入。

表单还可能保留旧值，同时其他组件刷新共享数据库版本。把新版本附在旧草稿上会绕过用户复核。另外，如果每次查询或命令都先构造包含全部集合和审计条目的快照，限制模型输出并不能限制内部内存分配。

## 决定

[企业工具](../../../../frontends/dsh/src/enterprise-tools.ts)对每次新的变更请求既有 DSH 审批服务，并要求 `allowed-once`。调用必须有所属 agent（智能体）；`never`、拒绝、取消或审批不可用均不修改记录。精确重放已提交命令不产生变更，无需额外审批。已认证的人工 HTTP 保存仍是用户发起操作。这项决定扩展 [ClawMaster 壳](../feature/2026-09-12-clawmaster-shell-over-dsh.zh.md)负责的企业行为，不另建策略引擎。

[CRM 与 ERP 表单](../../../../frontends/dsh/src/BusinessModules.tsx)将编辑版本与共享刷新记录分开保存。版本变化时阻止保存，在保留草稿旁展示当前值。明确复核表示同意按所展示版本保存整份草稿，不合并字段。已删除记录和已提交订单不能继续编辑。删除与提交确认在版本变化后失效。客户端明确传入已复核版本，并保留结果不确定写入的原命令标识。

[存储](../../../../frontends/dsh/src/enterprise-host.ts)在 SQLite 中负责集合过滤、计数与分页。SQL 标识符来自固定集合映射，用户筛选条件和偏移量使用绑定参数。连接内的 Unicode 小写匹配函数保留包含标点的 JSON 文本字面搜索。迭代按既有结果字节预算接纳记录，单条超限明确失败。分页携带版本，并拒绝跨页期间的数据变化。

审批准备读取目标记录、订单提交关联的库存，或已有回执。AI 提交通过与人工保存相同的事务实现返回单条持久回执。版本比较、命令标识、业务变更、审计插入与版本递增保持原子性。精确重放返回已存回执及当前版本；命令标识冲突复用会失败。Schema 2 增加数据库本地恢复代次。备份恢复原子导入记录和回执，但递增恢复代次而不导入备份中的代次。命令在查询回执及比较版本前检查所携带代次，审批后也再次检查。查询同时返回并校验代次和版本；旧协议请求归属代次零。表单捕获这两个值，任一变化均需明确复核。这可防止恢复重现旧版本号时，让旧请求再次生效。

## 考虑过的替代方案

**文件沙箱或仅提示词限制。** 两者均不能约束直接 SQLite 变更的权限。既有 DSH 审批服务已负责用户决定和委派 `never` 策略。

**自动将草稿推进到刷新后的版本。** 用户尚未核对新记录。明确复核既保留输入，也让覆盖决定可见。

**先构造完整快照，再裁剪输出。** 小型联系人查询仍会实体化无关审计历史。定向查询消除这部分分配，同时保留人工协议。

**为应用的每次读取分页，或省略启动校验。** 这些工具路径不需要重做完整存储；删除开库校验会削弱对无效持久数据的检测。

## 后果

AI 巡检在新的变更获得审批前保持只读。人工保存保留既有认证与事务行为。搜索可能扫描所选集合以统计匹配数；人工快照与保存响应、启动语义校验仍载入全部记录和审计历史。[前端限制](../../../../frontends/dsh/README.zh.md#known-limitations-and-deferred-work)不承诺无上限大库容量。

[工具测试](../../../../frontends/dsh/tests/enterprise-tools.test.mjs)覆盖真实 ToolRuntime 与 ApprovalService 的拒绝、单次审批和重放。SQL 访问跟踪在 2,000 条合成审计下拒绝无关集合读取，并覆盖字面搜索、字节上限和过期分页。[存储测试](../../../../frontends/dsh/tests/enterprise-host.test.mjs)保持回滚、版本检查和重新打开后的重放；[客户端测试](../../../../frontends/dsh/tests/enterprise-client.test.mjs)拒绝过期命令。[编译组件测试](../../../../frontends/dsh/tests/components-native.client.spec.mjs)在复核前保留旧输入，[录制业务流程](../../../../frontends/dsh/tests/business-tool-flow.test.mjs)记录审批结果，不使用真实模型。
