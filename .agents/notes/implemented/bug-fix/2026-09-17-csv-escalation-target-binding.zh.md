# Agent Note: bind CSV write approval to the requested paths

Status: implemented

[English](2026-09-17-csv-escalation-target-binding.md) | 中文

## Problem

CSV 写入可以请求一次性沙箱提权。通用审批理由没有说明审批涵盖哪个输入、输出和格式；异步审批也给调用方留下修改参数对象的时间窗口。

## Decision

`csv_process` 会在请求审批前解析标准化操作，并在 DSH 审批理由中列出输入路径、输出路径和格式。工具运行时会在等待审批前保存标准化参数和提权字段，审批结束后若操作已改变，就会在解析文件或写入前拒绝。DSH 工具分发会向工具传递稳定的参数值，因此调用方修改原始对象不能重定向已批准的输出。

此规则适用于 CSV 工具的一次性提权。它不会中介其他插件的任意文件系统副作用，也不构成进程隔离。

## Alternatives considered

- **保留通用审批理由。** 用户无法仅凭理由文本区分具体文件操作，因此审批信息不如实际写入目标明确。
- **假定参数对象永远不可变。** 当前运行时传给工具的是稳定值；显式比较可在调用方边界改变时继续约束审批对象。
- **将路径字符串审阅称为沙箱。** 显示路径无法阻止其他提供方或同进程插件访问文件；此工具仍依赖 DSH 文件系统强制执行访问策略。

## Verification

DSH 工具测试检查审批文本是否列出准确源路径和目标路径，并在审批等待期间修改调用方原始对象，验证写入仍限定于已批准目标。现有拒绝、取消、缺少审批服务和工作空间外路径测试验证这些情形不会创建文件。

## Consequences

- 审批记录会标明操作的源和目标。
- 分发后改变操作参数不会让一次性审批转向其他目标。
- 该保证只覆盖 DSH `csv_process` 路径，不代表所有插件、Shell、RPA、Office 或网络都受到统一强制执行。
