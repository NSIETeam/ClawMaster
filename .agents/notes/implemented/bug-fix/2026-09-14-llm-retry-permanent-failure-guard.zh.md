# Agent Note: 停止永久模型故障的无限重试

Status: implemented

[English](2026-09-14-llm-retry-permanent-failure-guard.md) | 中文

## 问题

`always` 重试模式把所有故障都当作可恢复，认证、配额、模型不存在、能力不支持和上下文溢出会持续发起相同请求。

## 决策

仅对临时故障保持无限重试。下游恢复逻辑获得首次处理机会后，`dsh-llm-retry` 对永久故障直接交回，不再安排重试；分类使用现有稳定错误码。

## Alternatives considered

**提高所有故障的重试上限。** 未改变凭据、模型或请求内容时，仍会重复无法成功的请求。

**由各 Provider 分别分类。** 会重复策略，并遗漏共享适配器产生的故障。

## Consequences

`always` 模式中的永久故障立即结束，临时故障保持原有行为。部署必须先修改请求或配置，再重试永久故障。

## Acceptance

- 永久故障不会追加 `llm/retry` 或计时器；
- 下游恢复仍先执行；
- 临时故障行为不变；
- 聚焦重试测试覆盖凭据、配额、上下文和未知模型故障。
