# Agent Note: 企业分页保留已复核版本，避免全库响应

Status: implemented

[English](2026-09-16-enterprise-paged-workspace.md) | 中文

## 问题

浏览器协议使用完整快照时，小型人工读取与保存也可能分配每条业务记录和审计条目。仅在浏览器中裁剪表格，仍会使传输量与 Host 内存随历史增长。局部列表也不能证明正在编辑的记录已删除，或已载入所有可选库存项。

## 决定

[共享企业存储](../../../../frontends/dsh/src/enterprise-host.ts)分别返回版本/计数元数据、集合分页和持久命令回执。模型与浏览器续页都携带 generation 和 revision；Host 拒绝已变化的数据集。筛选先于稳定 SQL 排序与分页。无筛选审计页使用修订区间，不逐条丢弃前面的记录。文本搜索读取列与关联物料标识；业务 JSON 字段名本身不属于搜索词。授权针对所选集合和记录，全局计数则需要广泛的记录与审计访问权限。

[客户端](../../../../frontends/dsh/src/enterprise-client.ts)为每个可见列表保留一页。编辑器保留独立的已复核版本，按 ID 读取当前记录，任一版本变化后均需明确复核。库存选择搜索有界候选页，并另行解析已选 ID。列表中没有记录不表示记录已删除。校验过的写入回执独立于后续读取确认成功；变更响应不确定时保留完全相同的请求标识。已知授权拒绝明确结束请求，不会重试。已放弃的分页读取不能覆盖之后的错误或数据。

浏览器行数/字节上限通过前端 Host 配置。若新变更的完整审计条目无法放入单记录页，事务拒绝变更，回滚业务效果、修订和成功历史。已有超限记录原样保留，并返回可恢复的字节上限错误。启动迭代全部记录与责任历史，校验领域事实、审计连续性和引用，保留唯一性检查而不载入完整快照。索引创建与语义校验仍处于原子的数据库迁移事务内。

[写入复核决策](2026-09-13-enterprise-reviewed-writes-and-bounded-queries.zh.md)仍负责模型单次审批与精确重放。本决定修改尚未稳定的浏览器 HTTP 响应，并同时更新客户端与桌面启动/重启冒烟。可移植备份格式 1 不变；分页索引不会替换已存记录。Host 与浏览器构建必须一起部署，因为概览/回执协议不支持旧快照消费者。

## 考虑过的替代方案

**渲染前抓取全部分页。** 每个请求虽然有界，浏览器仍保留全库分配，且必须等待无关集合载入后才能交互。

**并发编辑后继续沿用分页。** 插入、删除和排序变化会混合版本或遗漏记录。要求刷新可保留明确的已复核数据集。

**跳过启动校验或截断超限记录。** 两者都会掩盖无效或不完整的持久数据。迭代在限制驻留对象的同时检查每条记录；明确的大小错误保留已存内容。

## 后果

普通列表和保存响应不依赖审计历史总量。[容量报告](../../../../frontends/dsh/benchmarks/README.zh.md)通过生产 HTTP 处理器记录三档合成数据，包含真实序列化及源码和工作进程溯源。搜索/计数耗时与启动校验仍随数据量增长。显式文件操作遵循[备份工作进程决策](2026-09-16-enterprise-backup-workers.zh.md)。进程树预算和安装平台验收仍是独立问题。

[路由回归](../../../../frontends/dsh/tests/enterprise-pagination.test.mjs)覆盖过期分页、恢复、Unicode 字节、超限写入、启动语义拒绝与已取消请求。[客户端与渲染分页测试](../../../../frontends/dsh/tests/enterprise-restore.client.spec.tsx)覆盖跨页复核、库存选择、历史翻页与读取失败恢复。[录制模型场景](../../../../frontends/dsh/tests/business-tool-flow.scenario.mjs)从 Session JSONL 重建分页及其续页拒绝。
