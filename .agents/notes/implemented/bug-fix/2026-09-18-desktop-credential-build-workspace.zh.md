# Agent Note：在工作区安装凭据前端构建依赖

状态：已实现

[English](2026-09-18-desktop-credential-build-workspace.md) | 中文

## 问题

桌面发布构建会检查凭据前端产物。该脚本导入 `esbuild`，但凭据前端未加入 pnpm 工作区，因此干净的工作区安装不会链接它声明的开发依赖，桌面构建在生成安装包前失败。

## 决策

将 `frontends/credentials-keychain` 注册到两份工作区清单。常规的冻结工作区安装现在会在桌面产物检查前安装该前端声明的构建工具。

## 考虑过的替代方案

- **假设其他工作区包会间接提供 `esbuild`** ——干净安装不能保证这个前端的构建脚本能访问未声明的依赖。

## 后果

凭据前端仍独立版本化，运行时依赖不变。更新工作区锁文件时，必须包含凭据前端导入项及其开发依赖。
