# 企业容量诊断

[English](README.md) | 中文

## 摘要

[诊断程序](enterprise.perf.ts)在独立 Node 进程中通过编译适配器测量生产 SQLite 启动和已注册的 HTTP 处理器。它创建合成数据库，记录全部样本，并删除临时产物和数据。程序不打开用户工作区。这是维护者参考，不是已安装桌面应用的性能测试，也不是必需的 CI 时间门槛。

<a id="run"></a>
## 运行

按锁文件安装根目录和前端依赖，然后在自己管理的其他构建及基准均空闲时，从仓库根目录运行：

```sh
node --import tsx/esm frontends/dsh/benchmarks/enterprise.perf.ts --output /tmp/clawmaster-capacity.json
```

默认每个集合分别包含 100、1,000、10,000 条记录，每档采集五个独立进程样本。`--tiers 100,1000` 和 `--samples 3` 可选择较短的诊断。每档数量必须在 1 到 10,000 之间，样本数必须在 2 到 20 之间。每个工作进程限时两分钟。TypeScript 加载器仅用于编排；被测进程清除 `NODE_OPTIONS` 后，在普通 Node 下运行编译后的 JavaScript。

<a id="measurements"></a>
## 测量

每档包含等量客户、库存项和单行草稿订单，审计条目数量为每类记录数的五倍。二十家公司和十个供应商提供重复搜索词。诊断程序在一个 SQLite 事务中插入确定性的记录和对应审计历史，然后通过生产初始化重新打开数据库再测量；初始化会校验模式、外键、记录格式、审计连续性和责任历史。每个样本都在独立临时目录中接收已经关闭的种子数据库副本。

| 操作 | 计时终点 |
| --- | --- |
| `open` | 存储初始化和校验；不包含模块导入和进程启动 |
| `overview` | HTTP 版本、计数与已配置上限 |
| `list`、`search` | 首个客户分页，最多 50 条记录，使用默认 256 KiB 字节预算 |
| `auditTail` | 通过校验版本的修订区间读取最后 50 条审计记录 |
| `saveReceipt` | 修改一个现有客户并序列化命令回执 |
| `backup` | 工作进程导出并流式下载为 Blob |
| `prepareBackup` | 上传原始 Blob、工作进程校验及小型复核响应 |
| `restore` | 工作进程事务、授权检查与持久回执序列化 |

报告包含全部耗时样本、最近秩 p50/p95、响应字节、各操作前后 RSS、堆占用及Host 与子进程各自的峰值 RSS，以及两者峰值相加的保守上界。每项操作前执行 GC。HTTP 测量包含请求体、处理器、序列化和客户端解码；备份下载保留为 Blob，不包含已认证的 DSH 传输层及网络。测试程序在准备与恢复期间保留下载的 Blob，因此内存也包含放在被测进程中的模拟浏览器存储。即时回调记录 Host 事件循环的最大调度间隔，包含最终同步执行段。这衡量 Node 调度，不是浏览器输入延迟。

<a id="interpretation"></a>
## 解释

报告记录检出提交、工作树是否有修改、适配器与备份工作进程摘要、Node 版本、架构和机器内存。编译适配器使用检出目录安装的外部包。报告应与确切的检出版本和锁文件一同保留。不清除文件系统缓存；新进程不等于冷磁盘。报告中的 p95 是观测样本中的最大值，不能视为总体分位数估计。

列表和回执大小可以有界，但启动校验、备份和恢复的成本仍随历史增长。调查回归时需比较相同数据规模和操作终点。不要通过删除校验或历史来改善数值。验收限制和排除范围见[测量决策](../../../.agents/notes/implemented/testing/2026-09-16-clawmaster-enterprise-capacity.zh.md)。

<a id="measured-workload"></a>
## 实测负载

[0.2.4 候选报告](2026-09-18-candidate-b50d31.json)记录 Apple Silicon Mac、6 个逻辑 CPU、8 GiB 内存、Node 24.20.0 环境下每档三次的结果。报告标识干净源码提交 `b50d31a3d2cdb49a35282c512b2482b24d418958`，并记录编译适配器与备份工作进程的摘要。每个 p95 都是三次观察中的最大值，不代表总体分位估计。下表单位为毫秒，格式为 p50/p95；100/500、1,000/5,000 和 10,000/50,000 条业务记录/审计记录三档均已完成。

| 操作 | 100 条记录 / 500 条审计 | 1,000 条记录 / 5,000 条审计 | 10,000 条记录 / 50,000 条审计 | 响应字节数，100 / 1,000 / 10,000 |
| --- | --- | --- | --- | --- |
| 打开及完整校验 | 19.0 / 20.0 | 114.1 / 121.0 | 1136.8 / 1152.8 | — |
| 概览 | 18.8 / 19.4 | 20.2 / 20.5 | 24.9 / 26.1 | 169 / 174 / 179 |
| 首屏分页 | 3.1 / 3.3 | 3.2 / 3.2 | 3.6 / 3.7 | 9,016 / 9,018 / 9,020 |
| 搜索 | 1.0 / 1.1 | 3.1 / 3.3 | 5.3 / 6.0 | 995 / 9,052 / 9,052 |
| 审计尾页 | 3.1 / 3.2 | 3.2 / 3.5 | 3.8 / 4.0 | 20,559 / 20,562 / 20,565 |
| 保存回执 | 3.5 / 3.9 | 4.0 / 4.7 | 4.5 / 4.6 | 160 / 162 / 164 |
| 下载备份 | 85.4 / 90.8 | 216.7 / 233.0 | 1798.2 / 1995.4 | 405,127 / 4,091,334 / 41,394,341 |
| 上传及校验 | 81.3 / 82.4 | 181.3 / 185.8 | 1093.2 / 1249.8 | 267 / 272 / 277 |
| 确认恢复 | 98.7 / 104.1 | 315.7 / 344.0 | 2849.5 / 3101.7 | 144 / 145 / 146 |

三档保存回执均为 160–164 字节。导出文件约为 0.4、4.1 和 41.4 MB。所有被测操作中 Host 与子进程峰值 RSS 的最大和为 201.7、244.2 和 538.3 MiB；这是分别观测的进程峰值之和这一保守上界，并非同时采样值。本次测量只报告诊断成本，不构成验收预算或用户容量承诺。它不包含安装、已认证 DSH 传输、浏览器输入与绘制、冷文件系统缓存或外部应用，也不能证明已安装桌面验收或生产命令吞吐。
