# 纳瓦尔思维审视（Naval · Leverage & Long-Term Games）

核心等式：**财富 = 特定知识 × 杠杆 × 判断力 × 长期复利。** 财富是睡觉时也在增值的资产；金钱是转移财富的凭条；地位是零和游戏，别把追地位误当创富。审视一个问题就够了：**这件事做成之后，会不会自己滚雪球？**

## 何时使用

- 职业选择、创业方向、副业、内容创作、产品形态的取舍。
- 用户很努力但事情"越做越像搬砖"时——大概率是杠杆用错了。

## 工作流

### Step 1：特定知识检验

- 这件事在哪些点上需要**别人难以复制**的知识、品味或经验？没有这类点的想法，护城河只剩"比别人拼"。
- 这条特定知识是你天然会被吸引去钻研的吗（别人觉得苦你觉得玩），还是纯追风口？追风口的特定知识不特定。

### Step 2：杠杆审计（四类逐条过）

| 杠杆 | 特征 | 需要许可吗 |
| --- | --- | --- |
| 劳动力 | 最古老，管理成本极高，边际收益递减 | 需要（要招人管人） |
| 资本 | 放大快，但要看资方面色 | 需要 |
| 代码 | 边际成本≈0，睡觉时也在工作 | 不需要 |
| 媒体/内容 | 边际成本≈0，复制免费，24 小时替你说话 | 不需要 |

逐条回答：
1. 当前方案用的是哪种（哪几种）杠杆？
2. 有没有可能把重心挪到**无需许可**的杠杆（代码/媒体）上？
3. 这件事的**边际成本**是什么——每多服务一个用户/客户，要额外付出什么？趋近于零还是线性上涨？

### Step 3：长期博弈检验

- 这是**重复博弈**还是一次性博弈？重复博弈积累声誉、客户关系、技能复利；一次性博弈每次都从零开始。
- 复利载体是什么？（回头客、口碑、作品集、数据、技能）说出来。说不出来 = 没有复利载体，只是线性生意。
- 合作对象是"长期的人"吗（在乎声誉、玩无限游戏），还是捞一票就走？

### Step 4：地位游戏警告

检查这个想法是在**创造财富**还是在**争地位**：驱动力是"服务更多人的真实需求"，还是"显得成功、赢一场比较"？地位游戏零和、短暂、让人动作变形。不评判用户的动机，只把证据摆出来。

### Step 5：输出

```markdown
# 纳瓦尔审视：<想法/选择>

## 特定知识检验（有/无，在哪几个点）
## 杠杆审计表（当前杠杆 → 可迁移的无许可杠杆 → 边际成本）
## 复利评估（载体是什么，多久开始复利）
## 财富游戏 vs 地位游戏（证据，不评判）
## 判断：值不值得把你未来 3-5 年投进去
## 若做，形态改造建议（把它改成可复利的形态）
```

## 硬性规则

- 不灌鸡汤。每条结论落到用户的具体方案上，给证据。
- 劳动力杠杆不是耻辱，只是最重的一种；结论是"性价比排序"，不是道德排序。
- 涉及财务回报的判断标注不确定性，不承诺收益。
