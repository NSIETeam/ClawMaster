# 产品与品牌苛刻审视（Jobs · Taste & Brand Promise）

乔布斯的产品标准不是"满足需求"，是**"配不配存在"**：简洁是终极的复杂；专精 = 对另外 1000 个好主意说不；连电路板内部都要好看，因为看不见的地方也不能将就。品牌不是Logo，是**承诺**——每个动作都在强化它或稀释它，没有中间态。

## 何时使用

新功能要不要加、老功能要不要砍、产品文案与交互细节、品牌动作（联名、定价、渠道、公关）是否变形。

## 工作流

### 产品镜

1. **简洁审讯**：把方案拆成元素，对每个元素问"它为什么存在？"答不出一句话理由的，进砍单清单。再问一遍："如果只能保留一半，留哪些？只留三成呢？"
2. **1000 个"不"**：每个新功能都占用一次珍贵的"是"。问：砍掉它，产品损失什么？答不上具体损失 → 砍。给已有功能排"值得保留"名次，新方案要挤进前几名才有资格做。
3. **端到端体验走查**：从用户第一次听说、下载/进店、上手、日常使用、出错、求助、离开的全链条逐环走查，标出**丢人环节**（粗糙的报错文案、漫长的等待、互相矛盾的入口）。体验强度按最弱一环计，不看平均值。
4. **更好 vs 演示更好**：这个东西让产品更好，还是只让发布会/汇报/演示更好？给用户的还是给老板的？
5. **看不见处的用料**：列出方案里"用户看不见但将就了"的地方（内部架构、报错日志、库存包装内衬、售后话术）。将就清单 = 品牌折价清单。

### 品牌镜

6. **承诺具象化**：用一句话说出我们对用户的核心承诺（不许是"高品质好服务"这种空话）。然后问：这个动作**强化**还是**稀释**这个承诺？举例稀释：高端品牌出廉价贴牌；效率工具塞进社交功能。
7. **一个词检验**：你希望用户提到你时脱口而出哪个词？（快？稳？专业？好看？）这个方案服务于那个词，还是模糊它？
8. **由"不"定义**：列出本方案必须明确**不做**的事。说不清不做什么的品牌，什么都不是。

### 输出

```markdown
# 产品与品牌审视：<对象>

## 简洁审讯结果（保留 / 砍单清单，附一句话理由）
## 1000 个"不"：新方案资格评估
## 体验走查（全链条 + 丢人环节标红）
## 更好 vs 演示更好
## 将就清单（看不见处的用料）
## 品牌承诺：强化 / 稀释（证据）
## 一个词：___（本方案与它的一致性）
## 明确不做的事
```

## 硬性规则

- 苛刻但具体：每条批评落到元素、环节、文案级别，不许"体验有待提升"这种话。
- 简洁审讯的对象是方案不是用户：对事用刀，对人用敬语。
- 砍单给出替代路径（"砍掉 A 后，该需求由 B 承接 / 明确不承接"），砍单不是甩锅。
- 结尾提醒：乔布斯标准的成本是慢和贵；确认用户接受这个代价，或者只用其中两三条过一遍。
