PERSONAL GUIDE · 0.2.0-RELEASE

使用ClawMaster
进行个人管理

从学生的一周学习开始，把计划、知识点和实际完成情况连起来。让 AI 帮你整理和检查，由你决定日程、核对结论并保存成果。

适用于个人学习与日常管理 · 中文界面 · 下方课程、任务与进度均为虚构示例

01 / 准备

从一本自己的笔记库开始。

完成安装与模型设置后，从侧栏标签选择器打开笔记。它自带 Markdown 笔记库，无需安装 Obsidian。笔记保存在本机文件夹，适合学习资料与日常记录。

  1. 点击新建笔记，将笔记名称填写为“一周计划”，点击创建。
  2. 填入自己的可用时间与本周目标，点击保存。再打开一次，确认正文仍在。

先用示例练习。交给模型处理的笔记内容会发送至你配置的模型服务；API Key 不要写在笔记或任务描述里。

02 / 一周计划

把“想学完”写成可核对的成果。

假设小林本周有六小时自主学习时间。先写成果、预计投入和截止时间，保留一小时机动。下表可以作为“一周计划”的正文依据；换成真实使用时，补上具体日期。

虚构的一周安排：计划五小时，另留一小时机动
事项时间完成证据
线性代数周二前，二小时完成十道题，记录错因
英语阅读周四前，一小时读两篇文章，各写摘要
课程报告周五前，二小时一页提纲，标出三个来源

时间安排由你执行。先把课程、通勤等固定事项算进去；如果合计超时，减少本周范围，避免把每项都标成最高优先级。

03 / 计划检查

先检查可行性，再决定怎么调整。

打开 WatchDog，把模板粘贴到需要关注什么？，选择单次检查，点击开始检查。首次练习直接提供数据，无需先选目录。

应该看到

三项计划合计五小时，加机动共六小时；每项都有下一步和验收点。若模型自行增加课程或声称已经完成，在原会话要求按给定数据重查。确认后的安排由你复制回笔记并保存。

04 / 学习笔记

把知识点与本周目标连起来。

  1. 新建“线性代数”笔记，写下“概念、例题、错因、下次练习”四项，正文加入 #学习 和 [[一周计划]]，然后保存。
  2. 在“一周计划”中加入 [[线性代数]] 并保存。通过预览点击链接，确认打开的是对应笔记。
  3. 使用标签找同类内容，用搜索笔记查关键词；在目标笔记的反向链接中查看哪些笔记引用了它。

链接匹配多篇时选择正确对象；目标不存在时可创建这篇笔记。笔记标题明确一些，比给所有文件起名“复习”更容易找回。

05 / 每日总结

先记录事实，再让 AI 帮你整理。

每天结束时打开今日笔记，写实际完成和剩余问题，点击保存；再次点击会打开同一天的日记。也可把事实交给原任务会话整理，核对后批准追加。

AI 修改笔记需要单次批准。先核对日期、目标与追加内容再批准；拒绝或取消不会执行该次写入。看到成功回执后重新打开日记，确认原有内容还在，新增部分没有把六道题写成十道。

06 / 周复盘

用实际记录调整下一周。

周末在原会话明确指定“一周计划”、相关学习笔记与本周日记日期范围，请 AI 对照目标列出“完成证据、差距、原因待确认、下周调整”。缺少的日记应列为资料缺口，不能推断那天没有学习。

  1. 逐项回到原笔记核对，再决定保留、缩小或延后哪项任务。
  2. 把确定的结论保存为“周复盘”，链接到“一周计划”。给下周只留几个明确成果。
  3. 需要 AI 改正文时可先要求起草建议，在待审建议检查差异，再选择应用或丢弃。建议出现本身不代表正文已修改。

07 / 检查节奏

把重复检查用在已跑通的流程上。

先完成一次计划检查，再考虑将检查频率改为每天。它请求每二十四小时重复检查，不是固定晚上九点的日历预约；要在原会话核查实际安排、时间和停止方式。

应用必须保持运行，对应任务会话须有活动任务。结果返回原会话，不承诺手机通知、系统级提醒或日历同步。关闭后错过了检查，恢复时先核对记录，必要时补做一次。

08 / 保存与恢复

遇到问题，先保住草稿与原任务。

保存冲突或看到“笔记已被外部修改”？

当前草稿和磁盘新内容都被保留。先把草稿复制到安全位置，再核对最新内容；重新载入会询问是否放弃本地草稿。协调内容后再保存，别反复用旧稿覆盖。建议应用冲突时也要按最新笔记重新核对。

开始检查报错，目标暂时无法编辑？

原请求可能已经受理。选择打开原任务核查；需要重试时用重试原请求。先修正连接或模型配置，避免新建相同任务。任务显示“当前未运行”时仍需打开核对结果。

退出后，记录和草稿分别在哪里？

已保存的 Markdown 文件留在本机笔记库；退出前主动保存，未保存草稿不保证退出后恢复。备份整个笔记库，不要依赖自动跨设备同步。普通笔记即可完成本教程；OpenViking Memory 需要另行配置，不是安装即拥有跨会话记忆。
