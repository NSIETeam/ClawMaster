04 / 当前适用范围

从可控的小范围试用，
走向更完整的企业协作。

桌面 0.2.2 已发布：服务器更新通道、macOS 微信逐次授权读取，以及窗口和本地执行修复。安卓 0.2.2 新增文档工作区与持久化任务。完整企业管理中台仍在迭代。

现在适合做什么

个人或专人负责的本地工作台：整理办公资料、跟进任务、复核 AI 建议、管理本机业务记录。

企业落地还需完善什么

多人共享、组织角色与部门权限、外部 CRM/ERP 对接、结构化责任分派与验收，以及长期运行验证。

0.2.2 更新了什么？

桌面从服务器检查正式更新，GitHub 作为备用来源；macOS 标题栏独立留出红绿灯区域。Windows 修复更新缓存复用与知识索引路径，Linux 改善本地执行密钥保存。笔记批注、业务审批和 Office 保存冲突保护继续保留。阅读更新与使用指南 ↗

微信读取会一直监听聊天吗？

不会。macOS 试用功能只在每次批准后，读取你已打开、标题匹配的聊天中有限的可见消息。消息会进入当前会话及你配置的模型。它不读取全量历史、不后台监听，也不发送消息；真实微信版本的兼容性仍需单独测试。查看授权与使用步骤 ↗

旧更新接入包能直接升级所有组件吗？

已有独立更新器会保留其版本与设置，需要单独升级后才能使用新通道。符合条件的组件可在批准后热更新；DSH 核心和桌面外壳仍需安装更新。显示“已暂存”不代表已生效，单纯重启也不会自动应用所有暂存变更。了解不同更新方式 ↗

退出应用后，定时检查还会继续吗？

定时检查需要应用保持运行，并由活动任务会话接收。退出应用后不会继续后台巡检；设置频率后，请保持任务会话可用并复核实际执行记录。

可以直接连接企业现有的 CRM、ERP 和聊天平台吗？

当前 CRM/ERP 是本机单用户记录，并非企业现有系统的现成连接器。飞书、微信、企业微信、钉钉的连接取决于插件支持与账号配置，仍需逐项实测接入。

DSH 插件和模型配置能继续使用吗？

ClawMaster 沿用 DSH 运行时与模型配置方式，集成 Agent Teams、OpenViking Memory、dsh-im、Better Sidebar 和 Routing Suite。记忆与消息服务按需配置启用；兼容性以各插件及版本的实际验证为准。

办公文件编辑支持到什么程度？

支持基础 DOCX、XLSX、PPTX 的预览、编辑与保存。复杂排版、宏、加密文件和旧版二进制格式尚未完成兼容验收。切换会话、移动或移除面板、退出应用前，请先保存文件。

本地工作台意味着资料不会发送给模型吗？

应用和本地业务记录在你的电脑上运行与保存。使用模型时，完成任务所需的内容会发送到你配置的模型服务；请根据资料范围选择服务并设置权限。

05 / 下载 0.2.2

桌面与手机，

桌面版 0.2.2，安卓独立 Agent 0.2.2。请选择匹配系统与芯片的安装包；0.2.2 不再提供 Intel Mac 安装包。

桌面首次启动需联网准备 Node.js 与运行依赖。安卓不需要电脑或 Node.js；两端均需有效的在线模型配置，不包含离线大模型。

为什么不再提供 Intel Mac 版本？

从 0.2.2 起，ClawMaster 将 macOS 的官方构建、兼容性测试和问题修复集中到 Apple Silicon（M 系列），减少同时维护两套架构安装包及原生组件的成本。这是产品维护范围的调整；Windows x64 和 Linux x64 继续提供。

Intel Mac 用户可从 0.2.1 历史发布页找到旧版。旧版不包含 0.2.2 的新功能和修复，后续 Intel Mac 更新暂无发布计划；Apple Silicon 安装包不能用于 Intel Mac。

安装与升级前了解升级前保存编辑、结束任务并备份数据。macOS 尚未公证，Windows 没有发布者证书。仅从本页官方 Release 下载，并核对 SHA-256。自动更新仍需分别确认下载和安装。查看保留数据的升级步骤 ↗
本版验证范围

桌面 0.2.2：macOS 与 Windows 在发布测试机完成安装、窗口启动、正常退出与重开检查；Windows 测试不等同于 Windows Sandbox。Linux AppImage 与 DEB 完成解包、运行时重启、WatchDog 与编辑器检查，尚未完成原生桌面安装点击流程验收。安卓 0.2.2 在 Android 8 / 16 模拟器通过旧版覆盖升级、9 项设备测试与独立进程冷启动检查，包含 Office 容器、原生审批和系统任务执行。设备验收使用临时测试证书，最终 APK 另行验证与 0.2.1 正式证书一致，代码和资源与已测产物一致；模型使用记录型回复，尚未完成实体手机与真实模型账户验收。
