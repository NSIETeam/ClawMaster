01 / 使用范围

从手机里的小任务开始。

现在支持

模型对话、本机笔记的查找与读写、对话历史、写入确认、拒绝和取消。笔记与历史记录保存在应用私有目录。

不包含

桌面插件、电脑 RPA、网页自动化、后台定时任务、Graph Memory、CRM/ERP、跨设备同步和离线大模型。

模型请求需要联网和有效的服务商账户。手机能打开应用，不代表模型账户、余额或网络已经可用。

02 / 安装与配置

装好应用，再连接自己的模型。

  1. 从本页或官网下载区取得 APK，按需核对下载卡片中的 SHA-256。用手机打开文件，仅为当前安装来源按系统提示允许安装。
  2. 打开 ClawMaster 的“设置”，填写模型服务的 HTTPS 地址、模型名称和自己的 API 密钥。地址不要包含 /chat/completions。
  3. 保存配置，在“对话”发送一个简单问题。收到实际回复后，再开始处理需要的笔记。
应该看到

模型返回对话内容。若提示凭据、额度、地址或网络错误，先修正对应配置，再重试；不要把 API 密钥写进对话或笔记。

安装包没有预置 API 密钥或赠送额度，费用与可用模型由你选择的服务商决定。

03 / 第一条笔记

先用一条虚构记录练习。

可以发送：“请创建一条名为周计划练习的笔记，内容是：周三整理学习资料。这是虚构练习。”

  1. 等待模型提出笔记写入，检查标题与正文。
  2. 需要保存时确认；不需要时拒绝，或取消当前任务。被拒绝或取消的这次写入不应产生新笔记。
  3. 保存后打开笔记核对内容，再正常关闭和重新打开应用，确认笔记仍在。

笔记在审批期间被其他操作修改时，旧写入会因版本冲突被拒绝。重新读取并复核最新内容，不要用旧建议覆盖变化。

04 / 数据与升级

本机保存，不等于从不发送。

应用只申请联网权限，API 密钥通过 Android Keystore 加密。执行模型任务时，请求、相关笔记和工具结果会发送到你配置的模型服务；请按资料敏感程度选择服务。

卸载会删除本机笔记和历史。云备份与设备迁移默认关闭，需要保留的内容请先另行保存。删除模型密钥不会删除笔记与对话。

应用标识为 team.nsi.clawmaster.android。后续升级需要同一发布签名和更高版本代码；请从官方渠道取得更新，不要混装一次性测试证书签名的 APK。

05 / 验证与常见问题

看清已经测试的范围。

0.2.1 在 Android 8 和 Android 16 模拟器完成发布模式验收：写入确认、拒绝、取消、界面重建、密钥加密和重启后数据保留。另有 13 项核心及回环 HTTPS 检查通过。

设备测试使用记录型模型回复，尚未在实体手机或真实模型账户上完成端到端验证。最终 APK 使用固定发布密钥重新签名，程序和资源与通过验收的 CI APK 一致，签名验证通过。

为什么安装包很小？

这是原生安卓界面与本机 Agent 逻辑，不携带大模型权重，也不包含桌面运行环境。模型回复来自你配置的在线服务。

需要电脑保持运行吗？

不需要。应用在手机上运行，直接请求模型服务；当前不提供跨设备同步或后台定时任务。

已经上架应用商店了吗？

当前通过官方 GitHub Release 提供 APK，尚未上架 Google Play。
