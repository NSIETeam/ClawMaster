01 / 使用范围

从手机里的小任务开始。

现在支持

模型对话、本机笔记、对话历史、文档导入与文字预览、审批后修改与导出，以及后台继续运行和定时任务。0.2.2 新增 Office 文档和任务工作区，写入仍可批准、拒绝或取消。

不包含

桌面 DSH 插件系统、终端、电脑 RPA、浏览器自动化、Graph Memory、CRM/ERP、跨设备同步和离线大模型。安卓功能与桌面分别实现，不具备全部桌面插件兼容性。

模型请求需要联网和有效的服务商账户。手机能打开应用，不代表模型账户、余额或网络已经可用。

02 / 安装与配置

装好应用，再连接自己的模型。

  1. 从本页或官网下载区取得正式 APK，核对下载卡片中的 SHA-256。用手机打开文件，仅为当前安装来源按系统提示允许安装。已有 0.2.1 请直接升级，不要先卸载。
  2. 打开 ClawMaster 的“设置”，填写兼容 Chat Completions 的 HTTPS 模型服务地址、模型名称和自己的 API 密钥。地址不要包含 /chat/completions。
  3. 保存配置，在“对话”发送一个简单问题。收到实际回复后，再处理笔记或文档。
  4. 如需任务完成和审批提醒，在设置中选择“开启任务通知”，按安卓系统提示授权。通知权限只用于提示，不会代替你批准任何写入。
应该看到

模型返回对话内容。若提示凭据、额度、地址或网络错误，先修正对应配置，再重试；不要把 API 密钥写进对话或笔记。

安装包没有预置 API 密钥或赠送额度，费用与可用模型由你选择的服务商决定。

03 / 第一条笔记

先用一条虚构记录练习。

可以发送：“请创建一条名为周计划练习的笔记，内容是：周三整理学习资料。这是虚构练习。”

  1. 等待模型提出笔记写入，检查标题与正文。
  2. 需要保存时确认；不需要时拒绝，或取消当前任务。被拒绝或取消的这次写入不应产生新笔记。
  3. 保存后打开笔记核对内容，再正常关闭和重新打开应用，确认笔记仍在。

笔记在审批期间被其他操作修改时，旧写入会因版本冲突被拒绝。重新读取并复核最新内容，不要用旧建议覆盖变化。

04 / 文档工作区

导入副本，检查内容，再导出结果。

  1. 打开“文件”，通过系统文件选择器导入 DOCX、XLSX、PPTX、TXT、Markdown 或 CSV。每份文件最大 8 MiB，导入的是应用内私有副本。
  2. 先用不含隐私的练习文档发送：“请检查这份文档的文字，先列出建议，不要修改。”在文件页核对文字预览。
  3. 需要修改时说明准确内容。批准前检查目标文档、替换参数和当前修订；内容已经变化时，应重新读取后再确认。
  4. 检查保存结果，用文件页的导出操作选择保存位置。应用内修改不会覆盖外部导入原件，导入原件和旧修订仍保留。

适合的内容

Word 正文段落和顶层表格、Excel 已有单元格、PowerPoint 顶层文字形状。也可以提出新建 Word、表格或幻灯片文件的请求，再复核保存。

需要留意

预览以文字为主，不等同于 Office 排版。替换文字可能合并混合格式；表格替换值是普通文字，不是公式。不支持复杂排版、页眉、绘图、嵌入对象、公式计算、宏及数字签名文档。

05 / 后台任务与通知

安排执行时间，保留每次写入的决定权。

  1. 在“任务”填写提示词和开始延迟。先安排一个只读练习，例如：“整理我保存的周计划，列出待办，不写入任何文件。”
  2. 需要重复执行时设置重复间隔，至少 15 分钟。保存任务后，在设置中开启任务通知，以接收完成或审批提示。
  3. 遇到写入建议时，任务会暂停并保存建议。打开对应会话核对内容，只批准本次修改；安排定时任务不等于提前批准写入。
  4. 检查任务状态和已有结果，再决定是否重新运行。停止会取消所选定时任务，记录仍保留。

由你发起的运行可通过可见的前台服务在离开界面后继续。定时任务要求联网，可能产生模型费用；单次运行有八分钟上限，也可能被安卓提前停止。

后台执行不保证准点或一直运行。省电限制、强制停止及系统额度可能延迟或终止任务。只有成功的重复任务会安排下一次；失败、停止和中断不会。中断后没有保存回执的工具结果视为未知，不会自动重试；请先检查是否已有部分修改完成。

06 / 数据与升级

本机保存，不等于从不发送。

应用使用联网、网络状态、前台服务、任务通知和重启持久化权限；共享文件由你通过系统选择器指定，不申请广泛存储访问权限。API 密钥通过 Android Keystore 加密。执行模型任务时，请求、按需读取的笔记和文档、工具结果会发送到你配置的模型服务。

卸载会删除本机笔记、文档、任务记录和历史。云备份与设备迁移均关闭，需要保留的内容请先另行保存或导出。删除模型密钥不会删除笔记与对话。

从 0.2.1 升级时，先保存编辑并检查任务，再安装官方 0.2.2 APK。应用标识保持 team.nsi.clawmaster.android，版本代码由 201 升至 202；升级要求相同发布签名。若系统提示签名不兼容，保留原应用和数据，核对下载来源，不要通过卸载绕过。

升级后检查

确认历史会话和笔记仍在，模型设置仍可使用，再用虚构文档试一次批准和拒绝。CI 附件使用临时测试证书，不是供现有用户覆盖安装的正式包。

07 / 验证与常见问题

看清已经测试的范围。

0.2.2 已在 Android 8 和 Android 16 模拟器检查笔记、Office 文档、原生写入审批、界面重建、后台继续运行、定时执行及冷启动后的结果保留。

升级测试先向旧 0.2.1 写入虚构笔记、会话和模型设置，再覆盖安装 0.2.2 检查数据与密钥保留。这组模拟器测试将两个版本都签为同一临时 CI 证书，用于验证升级行为；正式发行包的签名和校验资料另见发行页。

设备测试使用记录型模型回复，尚未在实体手机或真实模型账户上完成端到端验证。这些结果不代表所有 Office 文档的格式兼容，也不保证所有手机的后台调度行为。

为什么比 0.2.1 的安装包大？

0.2.2 加入了 Office 文档处理所需的组件。应用仍不携带大模型权重或桌面运行环境，模型回复来自你配置的在线服务。

需要电脑保持运行吗？

不需要。应用在手机上直接请求模型服务。后台任务受安卓系统调度限制，当前不提供跨设备同步。

已经上架应用商店了吗？

当前通过官方 GitHub Release 提供 APK，尚未上架 Google Play。
